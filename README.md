# Atkin_Sieve_Project

Клиент-серверное приложение **«Решето Аткина»** для поиска всех простых чисел в диапазоне от `N1` до `N2`.

Сервер выполняет регистрацию пользователя, авторизацию, хранение истории поисков и вычисления с помощью решета Аткина, а клиент отправляет HTTP-запросы и отображает результаты.

## Возможности

- Регистрация и авторизация пользователя.
- Ограниченный режим без входа: поиск простых чисел, справка об алгоритме, выход.
- Поиск простых чисел в заданном диапазоне `[N1, N2]` алгоритмом **решето Аткина**.
- Проверка входных данных: `N1` и `N2` должны быть натуральными числами, `N1 < N2`.
- Вывод количества найденных простых чисел, времени выполнения и времени завершения поиска.
- Сохранение результата поиска в историю.
- Просмотр истории поисков пользователя.
- Удаление всей истории поисков.
- Справка об алгоритме.
- Смена пароля.
- Удаление аккаунта.

## Технологии

- **Язык:** C#
- **Платформа:** .NET 8.0
- **Сервер:** ASP.NET Core Web API
- **Клиент:** консольное приложение
- **БД:** SQLite
- **Тестирование:** автотесты .NET (6 тестов, все пройдены)
- **Среда разработки:** Visual Studio Code
- **ОС, на которой выполнялась разработка и тестирование:** Linux Ubuntu 24

## Архитектура

Приложение построено по клиент-серверной схеме:

```text
Console Client  →  HTTP-запросы  →  ASP.NET Core Web API Server  →  SQLite
```

- **Client** — консольный интерфейс: меню, ввод данных, отображение результатов, отправка HTTP-запросов, хранение токена авторизации.
- **Server** — Web API: регистрация, авторизация, проверка токена, работа с историей, запуск алгоритма решета Аткина.
- **SQLite** — хранение пользователей и истории поисков.

## Алгоритм

Решето Аткина — алгоритм поиска всех простых чисел до заданного предела. В проекте он используется для поиска простых чисел в диапазоне `[N1, N2]`.

Особенности алгоритма:

- использует квадратичные формы для предварительной маркировки чисел;
- эффективнее решета Эратосфена для больших пределов;
- временная сложность: `O(N / log log N)`;
- пространственная сложность: `O(N)`.

## Запуск проекта

### Требования

- .NET 8 SDK;
- SQLite (файл БД `atkin_sieve.db` уже находится в проекте);
- терминал или Visual Studio / Visual Studio Code.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Alisa-gh2/Atkin_Sieve_Project.git
cd Atkin_Sieve_Project
```

### 2. Запуск сервера

Откройте терминал в папке сервера и запустите:

```bash
cd atkinfolder/noclient/Server
dotnet run
```

Сервер должен запуститься и начать принимать HTTP-запросы.

### 3. Запуск клиента

Во втором терминале:

```bash
cd atkinfolder/noclient/Client
dotnet run
```

Клиент подключится к серверу и покажет консольное меню.

### Альтернативный запуск через Visual Studio

1. Откройте решение `atkin2/atkin2.0.sln`.
2. Запустите проект `Server`.
3. Затем запустите проект `Client`.

## Пример работы

При запуске клиента открывается консольное меню:

```text
=== Решето Аткина - Клиентское приложение ===
=== Аутентификация ===
1. Вход
2. Регистрация
3. Продолжить без входа (ограниченный функционал)
```

После входа доступно главное меню:

```text
=== Главное меню ===
1. Поиск простых чисел
2. Моя история поисков
3. Удалить историю поиска
4. Сохранить текущий поиск в историю
5. Информация об алгоритме
6. Выход
7. Управление аккаунтом
```

Пример поиска:

```text
Введите N1 (начало диапазона): 10
Введите N2 (конец диапазона): 25

=== Результаты поиска ===
Диапазон поиска: 10 - 25
Найдено простых чисел: 5
Простые числа: 11, 13, 17, 19, 23
```
